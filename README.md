🎮 RPG-aula

📖 Sobre o projeto

Este repositório reúne uma atividade de RPG desenvolvida durante as aulas de programação.

O objetivo é colocar em prática os conhecimentos de JavaScript e lógica de programação, entendendo melhor como os códigos funcionam e como as diferentes partes de um jogo podem ser organizadas.

💻 Tecnologias utilizadas

- JavaScript
- Git
- GitHub

📚 Aprendizados

Durante o desenvolvimento da atividade, venho praticando a escrita de códigos, a organização dos arquivos e a identificação de erros.

O projeto faz parte do meu processo de aprendizagem e poderá receber melhorias conforme eu avançar nos estudos.
